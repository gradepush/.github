Building a modular platform for teachers across disciplines.

GradePush Core is the starting point: an open-source, self-hosted alternative to GitHub Classroom for computer science teachers.

- **[GradePush Core](https://github.com/gradepush/gradepush)**: classrooms, individual and team assignments, and automated tests through GitHub Actions.
- **[GitHub CLI extension](https://github.com/gradepush/gh-gradepush)**: clone assignment repositories to your computer.

[Get started](https://github.com/gradepush/gradepush#self-host-with-docker) · [Report a bug or suggest a feature](https://github.com/gradepush/gradepush/issues)
