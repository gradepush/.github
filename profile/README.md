Open-source, self-hosted classrooms and assignments for GitHub.

Create classrooms, distribute individual or team assignments, and follow student progress. Repositories and automated tests stay on GitHub.

- **[GradePush](https://github.com/gradepush/gradepush)**: the application, installation guide, and local demo.
- **[GitHub CLI extension](https://github.com/gradepush/gh-gradepush)**: clone assignment repositories to your computer.

[Get started](https://github.com/gradepush/gradepush#self-host-with-docker) · [Report a bug or suggest a feature](https://github.com/gradepush/gradepush/issues)
